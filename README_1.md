# 🚲 누비자 세이프루트 (Nubija SafeRoute)

창원시 공영자전거 **누비자(Nubija)** 이용자를 위한 AI 기반 안전경로 추천 서비스입니다.
2026 창원시 AI 공모전 출품작 — 성산구·의창구 시범 구간 MVP.

> 🔗 **Live Demo**: _Streamlit Cloud 배포 후 여기에 링크를 채워주세요_

## 왜 만들었나

기존 자전거 길찾기는 "가장 짧은 길" 또는 "자전거도로가 있는 길"만 알려줍니다. 하지만 자전거도로 유무만으로는 실제 사고 위험을 설명하지 못합니다 — 자전거도로가 없어도 조용한 이면도로가 더 안전할 수 있고, 반대로 자전거도로가 있어도 교통량 많은 큰 도로라면 여전히 위험할 수 있습니다.

세이프루트는 창원시 공공데이터(도로망, 교통사고 이력, 자전거도로 현황)를 결합해서 도로 구간마다 **상대적 위험도**를 계산하고, 이동거리와 위험도 사이의 균형을 고려한 경로를 추천합니다. 특정 도로의 "사고 확률"을 예측하는 것이 아니라, 창원시 도로들 사이에서 **어디가 상대적으로 더 위험한지**를 비교하는 데 초점을 맞췄습니다.

## 핵심 기능

- **3가지 경로 비교**: 최단거리 · 자전거도로 우선 · AI 안전경로를 한 화면에서 비교
- **위험도 점수 (0~100점)**: 사고 이력 근접도(50%) · 도로 규모(30%) · 자전거 보호시설 유무(20%)를 반영한 가중합, 창원시 전체 도로 기준으로 정규화
- **예상 소요시간**: 평균 주행속도 가정 기준 추정 (경로 간 상대 비교용)
- **"피할 수 없는 위험 구간" 탐지**: 세 경로가 공통으로 지나가는, 우회할 수 없는 고위험 구간을 자동으로 찾아서 설명
- **추천 이유 설명**: 왜 이 경로가 나왔는지, 실제 계산된 수치(자전거 인프라 비율 · 큰 도로 비율 · 고위험구간 통과 횟수)를 근거로 매번 다른 설명 생성
- **지도 시각화**: 경로별 색상 구분, 고위험 지점 클러스터링 표시, 경로 on/off 토글

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 도로망 · 라우팅 | OSMnx, NetworkX, Shapely |
| 공간 데이터 처리 | GeoPandas |
| 지도 시각화 | Folium |
| 웹 앱 | Streamlit, streamlit-folium |

## 데이터 출처

- **도로망**: OpenStreetMap (OSMnx로 수집)
- **교통사고 이력**: TAAS 교통사고분석시스템(도로교통공단) 공공데이터
- **자전거도로 현황**: 창원시 자전거도로 공공데이터 (도로명 매칭)

## 실행 방법 (로컬)

```bash
cd saferoute_app
pip install -r requirements.txt
streamlit run app.py
```

`changwon_G_full_with_risk.pkl` 체크포인트 파일이 `app.py`와 같은 디렉토리(`saferoute_app/`)에 있어야 합니다 (창원시 전체 도로망 + 위험도 피처가 미리 계산되어 저장된 파일).

## 프로젝트 구조

```
changwon-saferoute/
├── README.md
└── saferoute_app/
    ├── app.py              # Streamlit 메인 앱
    ├── risk_routing.py     # 위험도 계산 · 경로 계산 · 지도 생성 백엔드 모듈
    ├── requirements.txt    # Python 패키지 목록
    ├── packages.txt        # Streamlit Cloud용 시스템 패키지 (GDAL 등)
    ├── DEPLOY.md           # Streamlit Cloud 배포 가이드
    └── changwon_G_full_with_risk.pkl  # 창원시 전체 도로망 + 위험도 체크포인트
```

> Streamlit Cloud에 배포할 때 **Main file path**를 `app.py`가 아니라 `saferoute_app/app.py`로 지정해야 합니다 (앱 파일이 저장소 루트가 아니라 `saferoute_app/` 폴더 안에 있기 때문입니다).

## 알려진 한계 (향후 과제)

- 위험도는 실제 사고 확률 예측값이 아니라 상대적 비교 지표입니다.
- 예상 소요시간은 평균 주행속도(15km/h) 가정 기반 추정치로, 신호대기 등은 반영하지 않았습니다.
- 사고 데이터가 위치 기반 집계 통계라, 사고 발생 원인(신호위반·과속 등)은 이번 모델에 포함되지 않았습니다.
- `highway=crossing`(횡단보도) 태그는 창원 지역 커버리지가 낮아(약 0.13%) 이번 버전에서는 제외했습니다.
